Welcome to MiniOS.

Select a pre-configured option from the boot menu, or press [Tab] key to manually edit the boot command line in order to
customize how MiniOS boots. A detailed description of various boot parameters is provided below.

* text: Boot into text mode without graphical interface
* automount: Enable automatic mounting of storage devices

* toram: Copy all data to RAM, allows ejecting boot device
  - toram=full: Copy everything to RAM
  - toram=trim: Copy only filtered modules to RAM

* nozram: Disable RAM compression (zRAM)
* zramcomp=[lzo|lzo-rle|lz4|lz4hc|zstd]: Set zRAM compression algorithm
* zramsize=[MB]: Set zRAM size in megabytes

* from=[path/device/URL]: Specify MiniOS data location
  - from=/minios: Use /minios directory
  - from=/dev/sda1/minios: Use specific device and path
  - from=http://server/file.iso: Download from HTTP
  - from=askdisk: Interactively select disk

* perch: Enable persistent changes (requires writable storage)
* perchdir=[resume/new/setup/ask/#]: Choose persistence session
  - resume: Auto-resume last session
  - new: Always create a new session automatically
  - setup: Interactively choose the session type and create a new session
  - ask: Interactively select a saved session; if none exist, enter setup
  - #: Use specific session number
* perchmode=[native/dynfilefs/dynblk/vmdk/raw/squashfs]: Set persistence mode
  - native: Direct filesystem (default, best performance, POSIX only)
  - dynfilefs: Expandable FUSE container (format 400)
  - dynblk: Compressed kernel block device (format 1; default 16 GiB)
  - vmdk: Split sparse VMDK block device, no compression
  - raw: Fixed-size ext4 image
  - squashfs: Resume an existing compressed snapshot
* perchsize=[MB]: Set or grow a DynFileFS, DynBlk, raw, or VMDK container size
* perchencrypt=luks: Encrypted LUKS2/ext4 container; prompts for a passphrase

* load=[filter]: Load only matching modules (regex or range)
  Examples: load=00-core or load=core,kernel,firmware or load=00,01,02
* noload=[filter]: Exclude matching modules  
  Examples: noload=05-xfce-apps or noload=xfce-apps,firefox or noload=05,06

For more information, visit https://minios.dev/docs
